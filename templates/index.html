Sistema de Optimización del Consumo de Servicios Públicos

Descripción del Proyecto

Este proyecto tiene como propósito desarrollar una herramienta digital que permita analizar y visualizar el consumo de agua y energía en hogares vulnerables.

La problemática abordada se centra en la dificultad en la gestión del consumo de servicios públicos debido a la limitada comprensión de la información reflejada en las facturas.

Desde la Ingeniería de Sistemas, se propone transformar datos técnicos complejos en información clara, comprensible y útil para la toma de decisiones.

🎯 Objetivo General

Desarrollar un sistema que permita analizar datos de consumo de agua y energía, generar visualizaciones simples y brindar recomendaciones para optimizar el uso de los recursos.

🛠 Tecnologías Utilizadas

  • Python
  • Pytest (pruebas automatizadas)
  • Git y GitHub
  • GitHub Actions (integración continua)
